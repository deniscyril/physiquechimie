Simulation d'un titrage colorimétrique

Réaction support du titrage
Montage
Modèle simplifié : chaque symbole représente un même « paquet » de quantité de matière.
⚠ Burette vide — réinitialise la simulation pour recommencer.

Avant l'équivalence : le réactif titrant versé est le réactif limitant — il est entièrement consommé dès qu'il tombe dans le bécher, il ne s'accumule pas. La quantité de réactif titré diminue à chaque ajout.

À l'équivalence : les réactifs ont été introduits dans les proportions stœchiométriques — ils sont tous les deux entièrement consommés. C'est le changement de réactif limitant. La relation à l'équivalence s'écrit :

n(réactif titré)initial / a  =  n(réactif titrant)versé à l'équivalence / b

où a est le coefficient stœchiométrique du réactif titré et b celui du réactif titrant dans l'équation de la réaction. Cette relation permet de déterminer la quantité de matière de réactif titré à partir du volume Véq versé à l'équivalence.

Après l'équivalence : le réactif titré est épuisé — c'est lui le réactif limitant. Le titrant versé ne réagit plus : il s'accumule dans le bécher et la solution se colore durablement. C'est ce changement de couleur persistant qui permet de repérer l'équivalence dans un titrage colorimétrique.
